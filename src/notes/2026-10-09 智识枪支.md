此外，在这篇文章里，我会主要用“LLM（大语言模型）”这个狭义说法指代当下的生成式 AI，包括 LLM 和其他技术基地的生成式 AI。有许多讨论将“生成式 AI”、“基于大模型架构的专门 AI”和“专门 AI”混为一谈，而我并不喜欢这样。

## 它擅长什么，它不擅长什么

作为一个会写一点代码的人，我无法阻止 LLM 入侵我的工作流。实际上，这个个人主页加博客的搭建也借了 LLM 的力，否则单靠手敲代码的速度是很难在一周时间里，在不使用 UI 库的前提下从 0 搭建 3 套完整且功能迥异的页面（主页、文章列表、文章页）的。作为后续的参考，我使用的工具链是 VSCode + Cline + DeepSeek v4.1 Flash，且没有使用现在流行的全 Agent 流程，而是相对传统的先手动规划架构，然后将“我寻思这个功能 AI 能帮我搞定”的部分尝试交给 Agent。

在不断“我寻思”过程中，我发现了一些有趣的规律。LLM 在具有**既定目标**和**既存参考**的任务上非常出色。例如我想将写在大组件中的一部分内容拆分成小组件，由我手动拆分的话，迁移模板与逻辑、补充导入、在原处替换，一套下来要个 5 到 10 分钟，还经常这里缺那里漏；而让 LLM 来做的话两三分钟就搞定了，还处理得很干净。文件重命名或跨文件变量重命名这类 `F12` 也经常遗漏的任务也常常完成得很好。

然而，一但**既定目标**或**既存参考**之间缺了一个，LLM 的表现就开始出现**断崖**式的下滑。就拿你正在看的这个文章页举例子，在**目录**的部分，我写了一个用于抽掉标题层级中没有被使用的层级的[小算法](https://github.com/idlist/id-sites/blob/ec1a78716a027017ea4dcd12a19f70483e3253f5/src/layouts/components/TableOfContents.astro#L18)。其实这个算法在我以前的旧博客里写过一个一模一样的，只是我一时半会儿找不到我写在哪儿了。一开始我是想让 LLM 来写的，因为当时已经连续奋战了好几天，大脑已经相当疲惫了，惰性和短期依赖让我第一反应寻求 LLM 的帮助。然而，来来回回共计 1 个小时的对话之后，这个算法还是没有写出来，你现在看到的版本是我花了 10 分钟手动写的。在这个例子里，缺失的是**既存参考**。

在这个观察中，关键并不在于 LLM 最后能不能达成这个任务。如果给足话费，或者换用能力更强的 LLM，单就这个例子中的任务大概率是能够解决的。关键在于这个**相对断崖**或许将永远存在。LLM 应用的舒适区间，是在既定目标和既存参考同时存在的时候，而在除此之外的场景中，它更像是一个稍微能找点规律的猴子打字机。或者换句话说，LLM 擅长的是执行广义上的**翻译**任务，而对于**新的东西**，哪怕只是上面的例子中这个十几行的小算法，LLM 都会需要付出成倍的努力。

而这并不是什么好事。

## LLM AI 并非“智识平权”

科技是一种放大器，若是未加规制，它让好的更好，而让坏的也更坏；LLM 也并没能逃脱这个范式。

“智识平权”这个词让 LLM 的作用听起来好像只有正面，而这或许也是一些人所期望的样貌。然而，这个词隐含的前提实在太多了，而我认为最不切实际的前提之一，便是默认使用者都具有合格的修养和良知。去掉这个默认之后，它所暴露出来的问题是显而易见的：它给了这些有着明确的想法，却受制于缺乏技术的人轻易地实现自身想法的机会，不论这究竟是美好愿景，还是**非分之想**。

有的人可能会乐观地认为拿着 LLM 做坏事的人或许占少数。但是，即使这个前提成立，在 LLM 特性和现实利益的双重驱动下，它们所造成的后果仍然是**灾难性**的。上面已经总结过，LLM 最擅长且同时是最便宜的用法的是从一个既存到另一个既存之间的**翻译**。那么，什么是能够利用这种广义翻译的同时，短期经济利益最高的行为？**洗稿、抄袭、破解**。这些行为的本质都是将一个现存的事物 A 翻译成价值毫无增加的事物 B，洗稿将前人的创作翻译成“原创”，破解将汇编码翻译回原本的代码。原本已经泛滥而由于人力瓶颈还得以对策的无价值创作，在 LLM 的手中被廉价地自动化，像滔天的洪水一般吞噬着整个互联网乃至公共知识库。最糟糕的是，LLM 的这种擅长与不擅长的领域区别导致它自身即使只是单纯地**存在**在这里供人使用，也在无形地鼓励着更加廉价的用法。“技术无罪论”这种乌托邦式的观点只在没有任何人使用这项技术的场景下成立，但现在的 LLM 显然不是这个情况。

那么，LLM 究竟像什么？在我看来，它更像是一把智识上的**枪支**：它放大了使用者的能力，放得太大了，以至于给予了他们只要想去做，就可以在整个公共知识空间里肆意破坏的能力；一些人已经沦为了这种破坏的牺牲品，而大部分人没有能够抵御这种破坏的手段。

并且，这把枪对于持有它的主人而言，也算不上绝对的安全。虽然这严格而言已经是另一个话题了，但是既然提到了，就简单说几句：过度依赖、技能退化、对于“学会了”的幻觉……只要使用的方式稍有不慎，为追求短期的效率导致的长期后果就会接踵而来；而当今 LLM 的存在方式却主动地迎合大脑的捷径偏好，刻意或无意地催生着不慎的使用方式。并且，“做一件事”和“借 LLM 做一件事”实质上是无法被动地互相转化的两种截然不同的技能，一些人在混淆之中享受着虚假的收获，而另一些人由于自身积累的技能与兴趣被两者的差异抹去而陷入痛苦。

如果你是“人人有枪，他才不乱”的支持者，那么我很佩服你看到了这里也还没有将这个页面关闭：现在你该关掉这个页面，去做点其他事儿去了。

## 创作之死、互联网之死

这篇文章从一开始就不是为了严肃地论证某个观点，这种事是学者们在论文上应该做的事，而不是一个没什么人看的个人博客该做的事。所谓之“创作之死、互联网之死”，它也不仅仅是一个从逻辑上推导出来的推论，更是我眼中正在发生的事实。

之前的分析里，我们已经获得了一个结论：在 LLM 的加持下，**既定目标**模糊、而**既存参考**也不甚明晰的**创作**并没有变得更加轻松，而两者都非常明确的**翻译**任务却变得十分轻松，且在当下的体系中蕴含着巨大的黑灰色利益。也许这个利益窗口只是昙花一现，但即使如此，它也已经造成了巨大的冲击：凭借一己之力，它让创作环境直接倒退了 50 年，甚至 100 年。当创作的命运是被轻易而廉价地复制，当创作者的名字被埋没在成堆的赝品里，这些过于负面的预期已直接成为在每一个由于自身的表达欲而提起笔的人在真正写下第一行字之前不得不面对的真实阻碍，而其结果往往是放弃。创作或许不会消亡，但在这种范式之下，它会大规模萎缩，或许重新回归富人的闲暇娱乐，或许重新化作权贵的附庸，就仿佛千禧年的百家争鸣只是一种遥远而虚幻的黄金文明。

互联网之死是这种推演的终极表现。我们就不说公地悲剧、劣币驱逐良币这种已经被念过不少遍的经了；就从一个更加朴素的角度出发：互联网正在（再次）成为**巴别图书馆**。从理论上讲，巴别图书馆中确实包含了人类的所有知识，但是其中几乎所有的内容是毫无意义的噪音；而充斥着越来越多的廉价 AI 生成物，实际价值却在被不断稀释的互联网，也正在化作这一表征的具象实现。当在公共空间搜寻由人类所作，为人类而作的内容这件事本身变得足够艰难，人们或许又将只能回归到部落式的信息交换，例如依赖熟人推荐；然而，互联网本身又同时身为人们通过共同的兴趣或爱好，跨越时空聚集成部落的平台，如果寻觅不到创作的背后那个真实的人，又如何凝聚成部落？这就好像一场被加速了的熵增，每个人之间的距离被越拉越远，真正的连结越来越难以形成，而剩下的只有沉寂。

我当然希望最终事情不会完全往这个方向滑落，但从我的观察出发所获得的结论不支持我下乐观的判断。任何人都可以尽情地在理论上驳倒我的观点以展示他们的智慧，但他们无法撼动我眼中的炎凉世态。我觉得最有意思的是那些口头上说着“万物自会找到出路”然后坐观其殆的人们，他们眼中的那抹冷漠是这个时代最真诚的底色。

## 智识的枪支已被到处分发

一般的文章到这里，往往会提出几个在表面上修修补补的建议作为最后的结语。但这篇文章不会这样：我不认为这个问题能够只靠表面的修补解决甚至缓解，因为不论是怎样的表面功夫，几乎都可以被现有的技术轻松绕过，而在目前的律法层面上极难追究。如果将这件事比作猫鼠游戏的话，老鼠一方正在以极快的速度变异与进化，后面的那只老猫步履蹒跚。

借用一句老掉牙的话：潘多拉的魔盒已然开启。打开这一轮盒子的是贪欲，是傲慢，还是想要抓住救命稻草的那一抹急切，现在已然不再重要；而已经大规模分发到每个人手中的 LLM 工具难以真正地收回，就如同已经开启的盒子无法再次关上。旧的正在加速消亡，而在狂热与不安的背后，新的样貌无人关心。
