这里是一些由一个 ID 是大写字母、小写字母和半角符号组成的人所写的一些零碎的笔记。你可以当它是一个 **博客**，虽然这个说法或许并不严谨。点击右上角的 <span style="font-family: var(--font-unique); font-weight: bold">前往 HOME</span> 可以去看看究竟是谁写了这些笔记。通过下方的 **地球仪** 按钮可以查看用其他语言写就的笔记，当然，界面语言也会跟着切换。

这些笔记依 **主题** 分类并列出。也许存在着这个笔记列表中并未列出的笔记，但那并非有意掩藏，只是零碎到不值得被归于任何主题罢了。
